## 🚀 Key Features

### **Core Architecture**
- **Modular Design**: Clean separation of concerns with `query_engine_bulk_glossary_v165.py` and `query_engine_entities_expanded_v165.py`
- **Fusion Detection Logic**: Combines keyword, semantic, and GPT-based detection for enhanced accuracy
- **Lazy Loading**: Optimized performance with on-demand data loading
- **Self-Testing Framework**: Comprehensive test suite with automated validation

### **Answer Generation Pipeline**
- **Strategic Thinking Lens**: 120-140 word domain-aware explanations
- **Story in Action**: 60-80 word field-customized case studies
- **Follow-up Prompts**: 2-4 domain-specific lens-shifting questions
- **Concept & Tool**: 2-4 relevant concepts with definitions

### **Domain Detection System**
- **Primary Domains**: negotiation, analytical_tools, strategy, human_behaviors
- **Application Fields**: operations, finance, defense, IT, education, sustainability, innovation, leadership
- **Consistent Priority Logic**: Unified domain prioritization across all sections

## 🚀 Deployment Instructions

### **Local Setup**
```bash
# Clone repository
git clone <repository-url>
cd GPTTutor-Decision

# Install dependencies
pip install -r requirements.txt

# Set environment variables
export OPENAI_API_KEY="your-api-key"

# Run tests
python query_engine.py --test
./run_tests.sh

# Start backend
python api_server.py
```

### **Production Deployment**
```bash
# Health check
curl http://127.0.0.1:5000/health

# Query test
curl -X POST http://127.0.0.1:5000/query \
  -H "Content-Type: application/json" \
  -d '{"query": "How to negotiate with a dealership?"}'
```
