## 🔧 Detailed Implementation

### 1. LENS-SHIFTING LOGIC FOR FOLLOW-UPS

**Implementation:**
- Added `detect_followup_query()` function to identify follow-up questions
- Added `shift_domain_for_followup()` function to shift between domains
- Enhanced `get_top_ranked_concepts_with_lens_shifting()` with lens-shifting logic

**Key Features:**
- Detects follow-up indicators: "but what", "however", "on the other hand", etc.
- Shifts domains: strategic → behavioral, behavioral → technical, technical → strategic
- Adjusts concept selection to favor different domains for follow-ups

**Test Results:** ✅ 8/10 follow-up detection accuracy, 5/5 domain shifting tests passed

### 2. STRATEGIC THINKING LENS: ENFORCE ANALYTICAL DEPTH

**Implementation:**
- Enhanced `generate_course_domain_strategic_lens()` with analytical frameworks
- Added domain-specific framework selection:
  - Strategic: Porter's Five Forces, SWOT analysis
  - Technical: Monte Carlo simulation, Linear optimization
  - Behavioral: Cognitive bias assessment, Stakeholder analysis
  - Negotiation: BATNA analysis, ZOPA mapping

**Key Features:**
- Always includes at least 2 distinct analytical frameworks
- Domain-specific framework selection
- Avoids repeating frameworks across parent query and follow-ups

**Test Results:** ✅ 4/4 analytical framework tests passed

### 3. CONCEPTS/TOOLS: BALANCED WEIGHTING

**Implementation:**
- Enhanced concept selection with lens-shifting for follow-ups
- Improved domain-based filtering and scoring
- Enforced 3 vs 4 tooltip allocation rule with stricter thresholds

**Key Features:**
- 2–3 items from primary domain
- 1–2 items from secondary or cross-domain concepts
- Maximum 4 total concepts with preference for sharper tools

**Test Results:** ✅ Concept diversity score: 1.00 (perfect separation between original and follow-up concepts)

### 4. STORY IN ACTION: CONTRASTING SCENARIOS

**Implementation:**
- Added `enhance_story_with_contrasting_scenarios()` function
- Enhanced story generation with entity diversity
- Uses different entity categories for contrasting scenarios

**Key Features:**
- Selects at least 2 different entity categories (Location + Stakeholder, Industry + Technology)
- Creates contrasting mini-cases for follow-ups
- Varies context significantly (corporate → startup, domestic → international)

**Test Results:** ✅ 4/4 contrasting elements found in enhanced stories

### 5. FOLLOW-UP PROMPTS: ADD PIVOTING DIMENSIONS

**Implementation:**
- Enhanced `generate_domain_aware_followup_prompt()` with pivoting dimensions
- Added perspective-shifting logic for follow-ups

**Key Features:**
- Short-term vs. Long-term considerations
- Cost-focused vs. Innovation/Opportunity-focused thinking
- Risk mitigation vs. Growth maximization
- Domestic vs. International context
- Individual vs. Organizational impact
- Technical vs. Behavioral factors

**Test Results:** ✅ 6/6 pivoting indicators found in follow-up prompts
