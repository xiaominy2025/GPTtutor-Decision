### **✅ PART 2 – Automated Format Validation in `test_suite.py`**

#### **New Validation Function**
```python
def validate_concepts_format(concepts_section: str) -> list:
    """Validate that concepts section follows the correct format"""
    warnings = []
    lines = [line.strip() for line in concepts_section.strip().split('\n') if line.strip()]
    
    if len(lines) < 2:
        warnings.append("⚠️ Less than 2 concepts provided.")
    
    for i, line in enumerate(lines):
        if ':' not in line:
            warnings.append(f"❌ Line {i+1} missing colon: '{line}'")
        if line.startswith('-') or line.startswith('*'):
            warnings.append(f"❌ Line {i+1} uses a bullet/dash: '{line}'")
        if len(line.split(':')) > 2:
            warnings.append(f"⚠️ Line {i+1} may contain multiple colons (check for clean format): '{line}'")
    
    return warnings
```
